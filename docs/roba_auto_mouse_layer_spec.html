roBa Auto Mouse Layer 仕様書

対象: ZMK firmware / roBa / PMW3610 トラックボール / Mouse Layer 周辺挙動

v1.0 トラックボール操作中だけマウスレイヤーを一時的に有効化し、クリック後も短時間維持するオートマウスレイヤー仕様。

1. 目的

トラックボール操作中だけマウス操作用レイヤーを一時的に利用し、クリック操作後もしばらくマウスレイヤーを維持する。 これにより、通常入力中はキーボードとして使いながら、ポインタ移動・クリック・戻る/進む・スクロール切替を少ない操作で行えるようにする。

設計方針
  • トラックボールを動かしたときに、必要な範囲だけマウス操作系へ寄せる。
  • クリック直後に即座に通常レイヤーへ戻らず、ダブルクリックや連続クリックを妨げない。
  • マウス操作中でも、ブラウザ戻る/進むやスクロールレイヤー切替を近い位置で扱う。
  • 通常の文字入力、ホームロウモッド、OS別ベースレイヤーへの影響を最小化する。

2. 関連レイヤー

レイヤー役割備考
LAYER_MOUSEマウス操作用レイヤークリック、戻る/進む、スクロールレイヤー切替を配置する。
LAYER_SCROLLスクロール専用レイヤートラックボールをスクロール操作として使うためのレイヤー。
LAYER_CLICKクリック補助レイヤー通常レイヤーから一時的にクリック系を扱う補助用途。
LAYER_BASE / LAYER_DEFAULT_WINmac / Windows の通常入力レイヤーOS別ショートカット差分はベースレイヤーで吸収する。

3. オートマウスレイヤーの基本動作

トラックボール入力によってマウス操作を開始し、一定時間マウス操作が続く前提で LAYER_MOUSE を維持する。 クリック操作は通常の &mkp ではなく、独自 behavior の &mqe を使い、ボタンリリース後に遅延してマウスレイヤーを解除する。

3.1 状態遷移

3.2 連続クリック時の扱い

クリックを再度押した場合、保留中のレイヤー解除タイマーをキャンセルする。 これにより、ダブルクリックや複数回クリック中にマウスレイヤーが途中で落ちない。

4. &mqe behavior

&mqe は「Mouse Key Press with Quick Exit」の意味で扱う。 通常のマウスボタン押下に加え、ボタン解放後に指定レイヤーを遅延解除する behavior とする。

4.1 パラメータ

項目現在値意味
layerLAYER_MOUSE遅延解除対象のレイヤー。
timeout-ms500マウスボタン解放後、レイヤーを解除するまでの待ち時間。
param1MB1 / MB2 / MB4 / MB5送信するマウスボタン。

4.2 押下時

  • 保留中のレイヤー解除タイマーをキャンセルする。
  • 指定されたマウスボタンを押下状態にする。
  • これにより、連続クリック・ダブルクリック中はマウスレイヤーが維持される。

4.3 解放時

  • 指定されたマウスボタンを解放する。
  • timeout-ms 後に LAYER_MOUSE を解除するタイマーを開始する。
  • タイマー満了前に再押下された場合は解除をキャンセルする。

5. Mouse Layer の操作仕様

現在の Mouse Layer は、主に右手ホーム周辺でマウスボタン操作を行う設計とする。

機能behavior用途
戻る&mqe MB4ブラウザやFinder/Explorerの戻る。
左クリック&mqe MB1通常クリック。クリック後も短時間 Mouse Layer を維持する。
右クリック&mqe MB2コンテキストメニュー表示。
進む&mqe MB5ブラウザやFinder/Explorerの進む。
Mouse Layer トグル&tog LAYER_MOUSE必要に応じて手動で固定化/解除する。
Scroll Layer トグル&tog LAYER_SCROLLトラックボールをスクロール操作へ切り替える。

6. Scroll Layer との関係

スクロール操作は Mouse Layer に直接混ぜず、LAYER_SCROLL として分離する。 Mouse Layer から Scroll Layer をトグルできるため、ポインタ操作中にスクロールへ移行できる。

分離する理由
  • カーソル移動とスクロールの誤認を避ける。
  • スクロール方向や速度を独立して調整できる。
  • Windows / mac のスクロール方向差分を sensor-bindings 側で扱いやすい。

7. Windows / mac の差分

オートマウスレイヤー自体は OS 依存をほぼ持たない。 左クリック、右クリック、戻る、進むは HID Mouse Button として送信されるため、Windows / mac で大きな差は出にくい。

操作Windowsmac評価
左クリック同じ同じ共通化しやすい
右クリック同じ同じ共通化しやすい
戻る / 進む多くのブラウザで対応多くのブラウザで対応概ね共通
スクロール方向設定差が出やすい自然なスクロール設定の影響あり個別調整対象

8. 安全性・誤動作対策

  • &mqe はクリック解放後に自動で Mouse Layer を解除するため、マウスレイヤーに入りっぱなしになる事故を減らす。
  • 解除までの 500ms はダブルクリックには十分で、通常入力へ戻る遅延としても許容しやすい。
  • 戻る/進むはページ遷移を起こすため、フォーム入力中は誤操作に注意する。
  • 破壊的操作、送信、削除、アプリ終了、ログアウトなどは Mouse Layer に置かない。
  • Mouse Layer 固定用の &tog LAYER_MOUSE を使う場合、解除手段を常に同じ位置に残す。

9. チューニング項目

項目初期値調整方針
timeout-ms500ms短くすると復帰が速い。長くすると連続クリックしやすい。
トラックボール移動による Mouse Layer ON 条件実装依存小さな揺れで入らないよう、必要なら閾値を設ける。
スクロール速度ZMK_POINTING_DEFAULT_SCRL_VAL 30速すぎる場合は下げ、重い場合は上げる。
Windows / mac のスクロール方向sensor-bindings で差分吸収OS設定と体感に合わせて反転/非反転を選ぶ。

10. 今後の拡張候補

  • Mouse Layer 自動解除の timeout をプロファイル別に切り替える。
  • ドラッグ操作時だけ解除を遅らせる。
  • トラックボール移動による Mouse Layer ON 条件に閾値を設け、誤発火を抑える。
